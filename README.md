# WargaPay - Sistem Keuangan RT & Sanitasi Lingkungan Digital

Landing page modern dan portal masuk warga untuk platform digitalisasi RT/RW terpadu.

## ✨ Fitur Utama
- **Hero 3D Interaktif**: Menggunakan Three.js dan React Three Fiber.
- **Transparansi Kas RT**: Pelaporan keuangan dan iuran warga secara realtime.
- **Smart Waste Management**: Pengingat dan otomasi jadwal daur ulang & pengangkutan sampah.
- **Portal Login Warga 50/50 Split-Screen**: Desain modern, minimalis, dan aksesibel dengan tema eco-friendly (#607C3C).

## 🚀 Tech Stack
- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Animation**: GSAP + ScrollTrigger, Framer Motion, Lenis Smooth Scroll
- **3D Graphics**: Three.js, @react-three/fiber, @react-three/drei
- **Icons**: Lucide React

## 📦 Menjalankan Proyek
```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev

# Build untuk produksi
npm run build
```
